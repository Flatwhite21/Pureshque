# Pureshque — Веб-платформа для расчёта КБЖУ, ведения дневника питания и анализа рациона

> **Учебный проект / Лабораторные работы №1, №4, №5**  
> Тематика: Веб-сервис для расчёта КБЖУ блюд, ведения дневника питания, отслеживания веса и глубокого анализа рациона.

---

## 1. Назначение и цель проекта

**Pureshque** — это современное веб-приложение, спроектированное для людей, стремящихся контролировать параметры своего питания, массу тела и качество рациона.

### Основные возможности:
* **Каталог продуктов:** пополняемая база продуктов с КБЖУ на 100 г, категоризацией и поиском.
* **Конструктор рецептов:** расчёт веса блюда, суммарного КБЖУ, КБЖУ на 100 г и на одну порцию с возможностью масштабирования количества порций.
* **Дневник питания:** учёт приёмов пищи (завтрак, обед, ужин, перекусы) по датам с мгновенным подведением итогов дня.
* **Персональная норма:** расчёт суточной потребности в калориях и макронутриентах по клинической формуле **Миффлина-Сан Жеора**.
* **Аналитика и графики:** визуализация потребления калорий по дням, соотношение белков/жиров/углеводов (круговая диаграмма) и динамика изменения веса.
* **Экспорт отчётов:** формирование дневника питания в **PDF** (с полем для подписи диетолога), каталога рецептов в **Excel (XLSX/CSV)** и аналитических отчётов.
* **Администрирование:** управление пользователями, модерация продуктов и рецептов, создание и восстановление резервных копий с синхронизацией с **Яндекс.Диск API**.

## 2. Инструкция по запуску и устранению ошибок на Windows

### 🐳 Вариант 1. Запуск через Docker (Рекомендуемый)

Убедитесь, что запущен **Docker Desktop**, откройте PowerShell в корневой папке проекта (`C:\Users\Sanya\Desktop\Pureshque`):

```powershell
# 1. Скопировать переменные окружения
Copy-Item .env.example .env

# 2. Запустить все сервисы (PostgreSQL, Redis, Django, Celery, Frontend)
docker compose up --build
```
> Примечание: в современном Docker Desktop используется команда `docker compose` (через пробел).

После запуска сервисы доступны по адресам:
* **Веб-интерфейс (Frontend):** [http://localhost:3000](http://localhost:3000)
* **Бэкенд REST API:** [http://localhost:8000/api/](http://localhost:8000/api/)
* **Админка Django:** [http://localhost:8000/admin/](http://localhost:8000/admin/)

---

### 💻 Вариант 2. Локальный запуск без Docker (Windows PowerShell)

#### 1. Запуск Frontend (из корневой папки проекта!):
Обратите внимание: файл `package.json` находится в **корне проекта** (`C:\Users\Sanya\Desktop\Pureshque`), а не в папке `backend`.

```powershell
cd C:\Users\Sanya\Desktop\Pureshque
npm install
npm run dev
```
Фронтенд запустится на `http://localhost:3000`.

#### 2. Запуск Backend (Django):
Откройте второе окно PowerShell:

```powershell
cd C:\Users\Sanya\Desktop\Pureshque\backend

# Создание виртуального окружения
python -m venv venv

# Активация окружения на Windows (не команда source!):
.\venv\Scripts\Activate.ps1
# Если PowerShell блокирует выполнение скриптов, выполните:
# Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
# и повторите: .\venv\Scripts\Activate.ps1

# Установка зависимостей
pip install -r requirements.txt

# Запуск миграций (автоматически использует SQLite, если PostgreSQL не настроен локально)
python manage.py migrate

# Запуск сервера
python manage.py runserver 0.0.0.0:8000
```

#### 3. Запуск тестов pytest на Windows:
```powershell
# Через виртуальное окружение:
python -m pytest tests/
```

#### 4. Проверка типов и линтинга (Frontend):
```powershell
cd C:\Users\Sanya\Desktop\Pureshque
npm run lint
```
